Como instalarlo

  1. Copia el snippet con el boton superior.
  2. Abre el editor de tu web o pasaselo a la persona que gestiona la pagina.
  3. Pegalo antes de la etiqueta final </body> o en el apartado de codigo personalizado del sitio.
  4. Guarda, publica la web y abre una pagina publica para comprobar que aparece el asistente.
En WordPress suele ir en un plugin de codigo tipo header/footer o en el footer del tema. En Shopify, Webflow, Wix o Hostinger Website Builder se pega como codigo personalizado antes del cierre del body.
Si necesitais ayuda con la instalacion, podemos hacerlo nosotros. Escribid a soporte@vantelia.es; necesitaremos acceso al proveedor de vuestra web o al HTML donde se debe insertar el snippet.

Buenas practicas

Pequenos habitos que reducen riesgos en el dia a dia.
  • No compartas tu usuario con otras personas del equipo.
  • Cierra sesion si usas un ordenador compartido.
  • Cambia la contrasena si alguien deja de trabajar contigo.
  • Usa el apartado Profesionales para gestionar el equipo, no cuentas compartidas.
Si necesitas cambiar el propietario de la cuenta, crear accesos para otras personas o revisar permisos, contacta con Vantelia y lo dejamos configurado sin afectar a tus citas.
