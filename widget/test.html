Chatbox embebido multiempresa listo para instalar en web corporativa

Esta pagina sirve para validar el flujo completo de Vantelia: carga del widget, respuestas con RAG, apertura de formulario, disponibilidad y registro profesional de solicitudes.

Checklist rapido

  • Pregunta por servicios, precios y horarios.
  • Pide una cita para abrir el formulario guiado.
  • Prueba varios horarios para validar bloqueos.
  • Comprueba la UX en escritorio y movil.

Snippet de instalacion

<script
  src="http://localhost:8000/widget/widget.min.js"
  data-api="http://localhost:8000"
  data-client="Clinica_Saga"
  data-position="right"></script>

Buenas practicas

  • Define `allowed_origins` por cliente en `config.json`.
  • Indexa la carpeta `data/cliente/` despues del onboarding.
  • Configura un webhook para integrar el lead con CRM o Make.
  • Usa HTTPS en produccion para el script y el backend.
