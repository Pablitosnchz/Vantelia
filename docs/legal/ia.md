# Aviso sobre uso de inteligencia artificial

Ultima actualizacion: 24 de abril de 2026

Este documento es una plantilla operativa inicial para Vantelia. Debe revisarse con asesoria legal antes de publicarse como version definitiva.

## Funcionamiento general

Vantelia puede usar modelos de inteligencia artificial para responder preguntas, orientar solicitudes, resumir informacion, generar propuestas iniciales y facilitar la gestion de citas o contactos.

## Limites

El asistente puede equivocarse, no entender correctamente una pregunta o responder con informacion incompleta si la base de conocimiento del cliente no esta actualizada. No debe usarse como sustituto de asesoramiento profesional en materias sensibles.

## Revision humana

Cuando una consulta sea importante, ambigua, urgente o tenga impacto legal, sanitario, financiero, contractual o reputacional, debe revisarla una persona del equipo correspondiente.

## Datos introducidos

No introduzcas datos especialmente sensibles, secretos empresariales, credenciales, datos de pago ni informacion de terceros sin autorizacion. Las conversaciones pueden registrarse para prestar el servicio, resolver incidencias y mejorar la calidad.

## Empresas cliente

Cada empresa cliente debe mantener actualizada su informacion, servicios, horarios, precios, politicas y condiciones para que el asistente responda con precision.

## Contacto

Para pedir revision humana o reportar una respuesta incorrecta, escribe a soporte@vantelia.es.
